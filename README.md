# 재단법인 맑고푸른곶 홈페이지 시안

재단법인 맑고푸른곶(https://sh-cabc.or.kr/)의 공개 정보로 만든 홈페이지 시안입니다.
서버 없이 동작하는 정적 HTML이며, GitHub Pages로 배포합니다.

| 파일 | 페이지 |
| --- | --- |
| `index.html` | 메인 |
| `about.html` | 재단소개 (인사말 · 설립배경 및 경과 · 비전·목표 · 조직도 · 오시는 길) |
| `measure.html` | 측정·분석사업 › 대기측정대행 |
| `equipment.html` | 측정·분석사업 › 주요장비 |
| `regen.html` | 재생사업 (활성탄재생사업 · 수집운반) |
| `consult.html` | 환경컨설팅 (컨설팅 · 환경교육) |

- `assets/style.css` — 스타일
- `assets/motion.js` — 애니메이션 (모션 필름, 스크롤 스토리, 장면 순환, 장비 필터 등)
- `images/` — 로고 · 사진
- `manifest.webmanifest` · `sw.js` · `icons/` — 설치형 웹앱(PWA): 홈 화면 · PC에 앱으로 설치, 오프라인 열람

## 앱으로 설치하기

- **안드로이드(Chrome)** · **PC(Chrome · Edge)**: 사이트 하단 '앱으로 설치하기' 버튼, 또는 주소창의 설치 아이콘
- **아이폰 · 아이패드(Safari)**: 공유 버튼 → '홈 화면에 추가'

새로 내보내면 서비스 워커의 캐시 이름이 바뀌어, 설치한 앱도 다음 실행 때 새 내용으로 갱신됩니다.

이 폴더는 Next.js 원본 프로젝트에서 `npm run export:html`로 만들어집니다. 내용은 원본 프로젝트에서 고친 뒤 다시 내보내세요.

로고 · 사진 · 문구 등 브랜드 자산의 권리는 재단법인 맑고푸른곶에 있습니다.
